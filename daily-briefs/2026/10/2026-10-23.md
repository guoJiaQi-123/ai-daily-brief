## 一、模型、产品与平台

### 1. OpenAI 决策 API 全面开放：只按输入 token 计费

- 当地时间 10/22，OpenAI 宣布全面开放决策 API（Decisions API），该 API 基于 GPT-6 Luna 构建，把模型智能聚焦于“限定答案（bounded answers）”问题，可基于文本、图像与结构化输入协助应用和智能体做准实时决策，响应速度比通过 Responses API 调用 Luna 最高快 10 倍。[IT之家](http://finance.sina.cn/tech/2026-10-23/detail-iniweiyu8006444.d.html)
- 定价：输入每百万 token 0.1 美元、缓存命中输入 0.01 美元，**仅按输入计费、输出免费**；公测以来新增原生 GPT-Live 集成、Prompt 缓存、美国与欧盟推理数据驻留；开发者现可传原生 JSON、在题目中带图，单次请求最多提交 400 个问题（为此前两倍），并在亚洲多地扩容。[36氪](https://m.36kr.com/p/3549468783041416)
- 同日官方还在开发者文档中公布 **Decisions API 与 Computer/Code/File 并列的应用类型分类**，并给出从 Responses 迁移到 Decisions 的指南，定位为高频、低延迟的判断型调用入口。[OpenAI Platform](https://developers.openai.com/api/docs/api/4916-decisions)

### 2. NVIDIA Minerva：AI 工厂的 AIOps 平台

- NVIDIA 于 GTC 柏林（10/22）正式发布 Minerva，把基础设施遥测与 AI 工作负载遥测合并分析，每小时处理数十亿数据点，可预测故障、把海量关联告警归并为单一工单并结合工厂拓扑给出根因，目标是提升 GPU 小时产出（goodput）、集群在线率与 token 产量。[NVIDIA Blog](https://blogs.nvidia.com/blog/minerva-platform-infrastructure/)
- 平台内置名为 “Sherlock” 的原生 AI 助手，支持自然语言查询集群健康、获取修复建议并一键触发自动化流程，并提供 MCP server 对接企业运维体系；硬件生态戴尔、联想、超微将集成，IREN 已在生产环境使用。[快科技/新浪](https://k.sina.com.cn/article_7857201856_1d45362c001908s3xe.html)
- 背景核查提示：10/22 的公开检索中一度无法独立确认 “Minerva AIOps” 的官方产品页，本条目已以 NVIDIA 官方博客为准；如官方页面后续调整，以官方为准。[Blockchain.News](https://blockchain.news/news/nvidia-touts-ai-factory-observability-in-minerva-announcement)
