## 一、今日重点：Google Cloud 推出 Gemini agent

Google Cloud 在 10 月 9 日的官方博客中介绍 Gemini at Work 2026，并宣布 Gemini agent。官方将其定位为可在工作中主动收集相关材料、进行推理、采取行动并完成工作流的企业智能体，而不只是对话式聊天机器人。::cite[10260]

新的智能体能力强调“从点工具到连续工作流”：它可以在较长任务中保持目标，使用组织内的知识、工具和第三方服务，并在需要时与其他智能体或员工协作。Google Cloud 同时强调 Gemini Enterprise 可从小型团队扩展到大型企业，帮助客户把分散的搜索、会议、文档、业务系统和流程自动化能力接入同一智能体层。::cite[10260]

行业智能体方面，面向金融服务和法律行业的 Gemini 版本已经进入 preview，政府、医疗和零售版本则标注为即将推出；金融服务场景聚焦研究、分析、报告和合规流程，法律场景聚焦合同、案件材料和知识工作。::cite[10260]

Google Cloud 披露，近 90% 的 Fortune 100 企业正在使用 Gemini Enterprise，近 80% 的 Google Cloud 客户正在使用 AI，并有近 500 家客户各自处理了超过 1 万亿 tokens。这些数字显示企业级 AI 已从试点转向更大规模的真实业务使用。::cite[10260]

## 二、OpenAI：GPT-6.1 Sol Ultrafast 模式 GA

OpenAI 官方发布记录显示，GPT-6.1 Sol 的 Ultrafast 模式已加入 Responses API。开发者可在使用 `gpt-6.1-sol` 时设置 `service_tier: "ultrafast"`，以缩短输出 token 之间的等待时间。该模式面向所有 API 用户开放，但仍受速率限制，并支持全球处理以及美国、欧盟数据驻留。::cite[10303]

今日中文渠道转述称，该版本同时进入 Codex 和 ChatGPT Work，速度最高可达 Sol 标准版的 8 倍，定价为标准版的 6 倍，输入和输出价格分别为每百万 tokens 12 美元和 60 美元；上述速度、定价和产品开放范围尚未在 OpenAI 发布记录摘要中完整确认，属于“第三方报道 / 待官方确认”。::cite[10238]

## 三、国内模型动态

### 1. Kimi K2.7 Code：继续聚焦 AI 编程（第三方报道 / 待官方确认）

快科技稿经中华网于今日转载，称月之暗面正式发布 Kimi K2.7 Code。报道称，该版本相较 K2.6 明显提升长上下文编程中的指令遵循、长程编程任务表现，并减少长程任务中的过度思考，平均 token 消耗下降 30%。::cite[10242]

报道列出的代码和 Agent 相关基准包括 Kimi Code Bench v2 提升 21.8%、Program-Bench 提升 11%、MLS Bench Lite 提升 31.5%，并在 Kimi Claw 24/7 Bench、MCP Atlas 和 MCP Mark Verified 等 Agent 基准上提升约 10%。由于暂未检索到月之暗面官方发布页，上述基准应视为第三方转述。::cite[10242]

### 2. 豆包实时语音大模型被传全量开放（第三方报道 / 待官方确认）

雪球用户今日凌晨发帖称，豆包实时语音大模型已正式推出，并在豆包 App 全量开放。该信息尚未检索到字节跳动或火山引擎的官方公告，暂不作为已确认发布，仅列为今日待核实动态。::cite[10240]
