## 智能体与产品应用

### Microsoft：从“构建 agent”转向“运营 agent fleet”

Azure Foundry Control Plane 页面把核心问题从单个 agent 能力，推进到企业级 agent 运行治理：它强调对输入、推理步骤、工具调用、输出、延迟和成本做端到端 trace；在生产流量上持续评估任务遵循、工具调用准确性、安全与质量；并在用户输入、工具调用、工具响应和输出等阶段设置运行时干预点。::cite[9969]

这说明大厂的企业 AI 叙事正在从 demo 与工作流自动化，转向更工程化的“上线后管理”：身份、权限、审计、告警、成本和漂移监控会成为 agent 平台的基础能力，而非增值插件。对企业开发者而言，是否能把第三方 agent 通过网关和 OpenTelemetry 纳入统一治理，将直接影响规模化部署速度。::cite[9972]
