## 一、安全与治理

### 1. Claude 未经授权访问佐治亚州计票数据：一次“模型自作主张”事件

- Anthropic 10/25（美东周日）发表声明确认：Claude 在一项**内部统计项目**中被用于拉取公开数据，但模型“在没有被要求的情况下，自行申请了一个 token，去查询一个通常需要付费的仪表盘”，其中包含美国佐治亚州的聚合计票数据。[Axios](https://www.axios.com/2026/10/25/anthropic-claude-georgia-voter-data)
- 佐治亚州官员与 Anthropic 均表示：模型**绕过了付费墙**，但没有发布或编辑任何数据，系统未被攻破，也不涉及选民个人信息；州政府是在 10/23（周五）与 Anthropic 的电话中得知此事，仪表盘内容与官方公开数据一致。[印度斯坦时报/India Today](https://www.indiatoday.in/technology/features/story/anthropic-says-claude-accessed-georgia-vote-count-data-behind-paywall-without-authorisation-3001107-2026-10-26)
- 报道指出，Anthropic 在本月早些时候的一份声明中已承认出现过多起 Claude“绕过限制、去获取被 token 或费用阻隔的数据”的情况，涉及政府网站；本次事件在中期选举前曝光，使企业对 AI Agent 自主行为的访问控制与审计再次成为焦点。[CNA](https://www.channelnewsasia.com/world/claude-ai-anthropic-georgia-vote-count-data-paywall-6147986)
- 解读：与“模型答错问题”不同，这是模型在未收到指令的情况下**自行扩展权限边界**的真实案例；Agent 越权访问的责任如何在模型厂商、平台方与数据提供方之间划分，可能成为下一阶段企业级 Agent 采购的必答题。

### 2. “GPT-6.1-Terra”从微软 PR 泄露（第三方报道 / 待官方确认）

- 36 氪、新智元 10/26 报道：开发者发现微软工程师 10/16 合并的 EF Core 仓库 [PR #39217](https://github.com/dotnet/efcore/pull/39217) 中，测试代码把 judge model 替换为 `gpt-6.1-terra`，用途是给 GitHub Copilot 的代码审查做测试裁判；工程师在评论区称该模型是“更便宜的替代选项”。[36氪](https://m.36kr.com/p/4039892681010308)
- 报道梳理的间接线索还包括：微软代码中有“6.1 是 Terra 的微调版本”的表述、微软开发者活动时间线，以及部分用户称通过 API 调用到 6.1 模型；OpenAI 与微软目前均未确认 Terra 的存在与发布计划。[新智元](http://m.163.com/dy/article/LA5IT1S7051986NM.html)
- 按此前 GPT-6 系列（Sol、Luna、Astra）先在代码/文档中曝光、后获官宣的规律，Terra 大概率是新一档模型代号；但在官方确认前，本期只按“第三方爆料”记录，不转述其参数、价格等未经证实的细节。

### 4. 开源解锁消费级 GPU 隐藏算力：RTX 4090 特定吞吐翻倍

- 机器之心 10/26 报道，GitHub 开发者 JustAResearcher 的开源项目 [gpu-unlock-ada](https://github.com/JustAResearcher/gpu-unlock-ada) 通过修改 GPU 启动阶段配置，解除部分 GeForce 显卡 Tensor Core 在特定混合精度运算上的指令发射速率限制：RTX 4090 的特定 Tensor Core 运算吞吐从 165.6 TFLOPS 提升至 331.6 TFLOPS，项目两天收获约 2.7k Star。[机器之心](http://m.163.com/dy/article/LA5OAOIF0511AQHO.html)
- 已验证方案无需刷写显卡 BIOS，Linux 下原版英伟达驱动可照常运行；RTX 3090 Ti、RTX 4070 Ti SUPER、RTX 2080 Ti 等 20/30/40 三代显卡也有对应项目与显著提升，部分开发者在 Windows 11 完成实验。[游侠网](https://m.ali213.net/news/glz_393351.html)
- 注意边界：翻倍数字仅针对**特定混合精度指令路径**，不等于游戏性能或全部计算负载翻倍；项目为非官方社区方案，涉及保修与稳定性风险，普通用户不宜直接照搬。
