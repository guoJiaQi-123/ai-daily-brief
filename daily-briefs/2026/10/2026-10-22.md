## 产业 / 公司动态

### Google Cloud × OpenAI

Google Cloud 官方博客在 2026/10/22 宣布，正式将 OpenAI 模型加入 Model Garden。首批包括 **GPT Astra**、**GPT 6.1 Sol**、**GPT 6.0 Luna**：Astra 面向高难度编程、Computer Use、专业任务与科学研究；Sol 强调以较低成本提供 Astra 级能力；Luna 面向大规模日常任务。Google 同时强调企业级数据边界、隔离访问、统一审计与单一账单，并称这些模型目前面向特定企业客户私有预览。[Google Blog](https://blog.google/intl/zh-tw/products/cloud/google_cloud_brings_openai_models_to_customers/)

### Anthropic：Claude Duet 主动式 Agent

Anthropic / Claude 官方页面显示，**Claude Duet** 是面向专业人士和小企业主的主动式 Agent 应用，研究预览从美国 Pro / Max 用户 waitlist 开始。Duet 可基于 Claude 账户的记忆、技能与连接器工作，在后台持续处理任务，并在发送消息、付款、签署文档、删除内容等关键动作前请求用户确认。[Claude](https://claude.com/resources/articles/claude-duet)

### OpenAI：Workspace Agents 进入研究预览

OpenAI 官方页面称，**Workspace Agents** 可在 ChatGPT 工作区内创建并分享给团队使用，支持按计划执行重复性任务、跨 Slack / Google Drive / Microsoft 应用等工具收集信息与执行操作，并通过角色权限、审批检查点、审计记录与监控机制控制自动化边界。页面说明该能力目前以研究预览形式提供给 ChatGPT Business、Enterprise、Edu 和 Teachers 方案。[OpenAI](https://openai.com/zh-Hant/business/workspace-agents/)

## 开源 / 工程生态

### Google Cloud Model Garden 扩展为多模型企业入口

本次 Google Cloud 与 OpenAI 合作的工程意义在于：企业可在统一平台中按工作负载选择不同模型，并通过 Google Cloud Marketplace 汇总用量、账单与承诺消费；Google 还强调第三方 / OpenAI 工作负载的提示词、上下文与输出保留在指定数据边界内，且后续提供零数据保留选项。[Google Blog](https://blog.google/intl/zh-tw/products/cloud/google_cloud_brings_openai_models_to_customers/)

### Walmart Agent Gateway：Agentic Commerce 的 MCP 接口（第三方报道）

TechCrunch 报道称，Walmart Agent Gateway 是一个 MCP Server，用于让获批 AI Agent 连接 Walmart 与 Sam’s Club 库存并代用户购物；配套的 Agent Profiles 预计下月推出，用于区分 Agent 交易、设置每笔审批或消费额度，并允许用户随时删除 Agent Profile。因未检索到 Walmart 官方原文，本条按第三方报道处理。[TechCrunch](https://techcrunch.com/2026/10/21/while-amazon-blocks-ai-agents-walmart-rolls-out-the-welcome-mat/)
