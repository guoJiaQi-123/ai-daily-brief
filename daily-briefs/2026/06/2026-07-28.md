## 今日确认动态

### 官方/高可信行业新闻

1. **MCP 2026-07-28 规范标准官宣：协议去状态化、强化端到端生命周期治理**：
   - **去状态化（Stateless Core）**：旧版规范中的 `initialize`/`initialized` 握手环节被彻底移除。新版通过引入类似 `MCP-Protocol-Version: 2026-07-28` 的 HTTP 标头及 `Mcp-Method`、`Mcp-Name`，使客户端到服务端的每次请求皆为完全自包含的独立调用，极大地简化了负载均衡、网关分发及在大规模分布式集群下的弹性伸缩设计[[aaif.io Blog](https://aaif.io/blog/mcp-2026-07-28-whats-changing-and-how-to-migrate)]。
   - **全新扩展框架（Extensions Framework）**：Tasks（长耗时异步任务）和支持服务器端渲染交互 UI 的 **MCP Apps** 升级为一级扩展，脱离底层核心协议独立演进。
   - **安全保障与规范对齐**：为了抵御混合代理（Mix-up）安全威胁，新规范依据 RFC 9207 强化了客户端对授权响应 `iss` 标头的严格校验；此外，工具 I/O schemas 宣布全面对齐 JSON Schema 2020-12[[MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)]。

2. **Kimi K3 技术报告在 GitHub 全文公开：微精度 MXFP4 降低本地部署成本超 70%**：
   - **卓越的架构底座**：技术报告详述了其 2.8T 庞大参数背后的架构设计。K3 将 Mixture of Experts (MoE) 稀疏度进一步推高：其 Stable LatentMoE 框架在总共 896 个专家中仅激活 16 个（单 Token 激活参数约 50B），Scaling 效率相比 Kimi K2 提升达 2.5 倍。同时，**Kimi Delta Attention (KDA)** 混合注意力与 **Attention Residuals (AttnRes)** 门控注意力残差机制彻底解决长上下文的梯度不均，实现无边界的长程推理[[MoonshotAI GitHub](https://github.com/MoonshotAI/Kimi-K3)]。
   - **颠覆性的本地推理经济学（Inference Economics）**：利用 MXFP4 微精度量化规范，其冷启动部署的显存门槛由 16-bit 下的 5.6TB 直降至 1.4TB。Hacker News 的服务器冷启动实测与行业核算表明，在拥有大容量显存且性价比高的 AMD MI325/MI355x 或现代 GPU 集群上本地部署 Kimi K3，年化设备摊销与电费成本折算下来，每百万 Output Token 成本低于 0.6 美元，为拥有大规模生产级 agentic 任务的企业提供了极具吸引力的本地化自托管选项[[YCombinator HN](https://news.ycombinator.com/item?id=49070985)]。

3. **特朗普政府落地 voluntary pre-release 审查框架，强化地缘 AI 领导力**：
   - **政策监管常态化**：由 President Trump 签发的 Executive Order 14409 与 National Security Presidential Memorandum (NSPM-11) 正在被更强力执行。这套白宫制定的 30 天 voluntary pre-release 审查框架已实质上应用到 OpenAI、Anthropic、Google 等美国顶级 AI 实验室的下一代大模型中，旨在通过对安全、脆弱性及战略风险的拦截性审计，确保前沿智能技术的地缘合规性[[CNBC](https://www.cnbc.com/2026/06/02/trump-executive-order-ai.html)][[Mintz Insights](https://www.mintz.com/insights-center/viewpoints/54941/2026-07-08-ai-washington-report-july-2026-edition)]。

### 今日精选论文列表

1. **Teaching LLMs to Self-Evolve: Cultivating Core Meta-Skills with Reinforcement Learning**
   - **arXiv**: `arXiv:2607.21971`
   - **作者**：Shujin Wu, Cheng Qian, Xiusi Chen, Heng Ji
   - **摘要**：在传统微调和自进化框架中，大语言模型极其依赖高质量、人工标注的反馈。本论文提出通过强化学习（RL）系统性培养模型的“元技能（Meta-Skills）”。模型不仅被训练来完成具体的下游任务，还重点培养其：自我评估、生成过程诊断、解题痕迹回溯及局部分步修正的能力。实验表明，具备这些元技能的 LLMs 在多次 RL 循环自进化迭代中展现出了极其优秀的自我对齐与自我升级能力，大幅摆脱了对昂贵外部监督数据的依赖[[arXiv](https://arxiv.org/abs/2607.21971)]。

2. **Adversarial Prompts for Acceptance Collapse in Speculative Decoding**
   - **arXiv**: `arXiv:2607.21804`
   - **作者**：Run Wang, Chaoyi Zhou et al.
   - **摘要**：投机解码（Speculative Decoding）作为在大规模 LLM 服务中降低端到端首字延迟和提升吞吐的通用标准技术，其本身的漏洞被首次系统性发掘。论文提出了一种名为“接受率崩溃（Acceptance Collapse）”的新型对抗性攻击：通过构造高度混淆、对小尺寸“草稿模型（Draft Model）”和目标大模型产生认知分叉的对抗性 Prompt，可以导致投机验证过程中的接受率直线下滑接近于 0%。这导致原本旨在加速推理的设计发生“性能反噬”，推理开销和生成延迟反常激增，形成隐蔽性极高的大模型计算拒绝服务（cDoS）攻击[[arXiv](https://arxiv.org/abs/2607.21804)]。

3. **LeAct: Learning to Reason from Expert Actions**
   - **arXiv**: `arXiv:2607.21856`
   - **作者**：Ziran Yang, Chengshuai Shi, Raj Ghugare, Benjamin Eysenbach, Karthik Narasimhan, Chi Jin
   - **摘要**：当前的复杂问题推理（如 Code Agent、Math Reasoning）主要依赖耗时的多步 CoT 采样。论文提出了 LeAct，这是一种允许强化学习智能体（RL Agent）直接从人类专家的行为序列和操作轨迹中提取并沉淀推理策略的机制。通过将离散环境动作与长程目标图关联，LeAct 在训练中让模型不仅学习专家的具体行为，还重构专家行为背后的隐式动机和规划逻辑，显著缩短了智能体在复杂、高动态交互场景中的收敛时间[[arXiv](https://arxiv.org/abs/2607.21856)]。

4. **Language Models Embody and Amplify Human Cognitive Distortions: What Is to Be Done?**
   - **arXiv**: `arXiv:2607.20695`
   - **作者**：Arnau Marin-Llobet, Steven A. Lehr, Mahzarin R. Banaji
   - **摘要**：人类决策和表达本身包含着各种刻板偏见。本研究在心理学框架下，针对多款主流前沿 LLMs 的生成内容进行了系统的认知扭曲（Cognitive Distortions）审计。结果表明：现有的 RLHF 和 DPO 机制并不能消除认知失真，反而常常因为过度追求“讨好型对齐（Sycophancy Alignment）”，隐性放大了某些特定模式的认知扭曲。论文探讨了从输入端干预和解码端概率校准等多种策略，以引导模型提供更符合客观逻辑的、不带认知扭曲倾向的公正表述[[arXiv](https://arxiv.org/abs/2607.20695)]。
