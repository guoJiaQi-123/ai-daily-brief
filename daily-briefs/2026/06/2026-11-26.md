## 🤖 重要论文 / 模型发布

- **DAiSy: 基于自适应效用估计的 LLM 预训练在线数据选择方法**：来自 Simin Fan 等研究员的最新论文提出了 DAiSy。该方法采用模型感知的在线数据自适应效用估计，绕过了传统方法在前后向传递中的庞大开销，有效解决了海量预训练数据筛选的算力瓶颈。[[ArXiv]](https://github.com/Chestnuts-Sisyphus/gittok/issues/2104)
- **Steerable by Design: 条件预训练实现大语言模型强可控对齐**：Henry Castillo 等人的论文引入了“条件预训练（Conditional Pretraining）”技术，使得大语言模型在最底层架构层面即具备稳健的可控对齐特征，彻底改变了传统上仅依赖最后 1% 的后训练微调或推理干预来实现对齐的安全路径。[[ArXiv]](https://github.com/Chestnuts-Sisyphus/gittok/issues/2104)
- **OpenClaw 智能体平台发布 2026.11.10 版本**：多智能体开源平台 OpenClaw 宣布发布最新版本，支持深层研究能力（Deep Research）及自主浏览器控制接管（Browser Handoff）。[[Newsference]](https://newsference.com/d/2026-11-26)
- **Anthropic Messages API 后端架构全面迁移至 Rust 语言**：Anthropic 官方证实已成功将其核心 Messages API 后端服务全部从 Python 迁移至 Rust，并同时推出了将 Claude Artifacts/In-Chat 应用一键转为本地桌面端独立应用的新功能，大幅度优化高吞吐智能体交互的执行延迟。[[Newsference]](https://newsference.com/d/2026-11-26)
