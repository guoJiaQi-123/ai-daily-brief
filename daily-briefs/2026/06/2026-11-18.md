## 今日要点

- **OpenAI 重磅发布新一代模型 GPT-6.2 Astra 与 GPT-6.2 Sol**：OpenAI 于 11 月 17 日晚（北京时间 11 月 18 日）正式发布其新一代 closed 系列模型 GPT-6.2 Astra 和 GPT-6.2 Sol。作为前沿推理系列的新旗舰，Astra 的 API 每百万输入/输出 Token 价格分别降至 $8.00 和 $40.00（比 GPT-6 Astra 降低 20%），且缓存输入大幅降低 60% 至 $0.40。Sol 则是面向高性价比、超快日常任务的定位，每百万输入/输出 Token 价格维持在 $2.00 和 $10.00。两个模型均支持 105万 (1,050,000) token 超大上下文与 128k 最大输出，并已在 ChatGPT Work、Codex 及 API 同步上线。Astra 在 Artificial Analysis 智能指数中取得 62 分，位居全球第二，仅次于 Claude Fable 5.2（来源：[OpenAI / Marktechpost](https://www.marktechpost.com/2026/11/17/openai-gpt-6-2-astra-sol-release/)）。
- **Alibaba Cloud 推出国内新旗舰 Qwen4-Max，参数突破 2.4 万亿**：阿里巴巴于 11 月 16 日晚正式推出其 Qwen 4 系列首款旗舰大模型 Qwen4-Max。模型建立在全新 MoE（混合专家）架构之上，拥有原生视觉能力和 1M 字符上下文。其在 QwenCloud 的 API 定价为：每百万输入 Token 约 $1.50（在一些三方平台和国际服务上略低于该标准），每百万输出为 $4.50。相较 Qwen3.8-Max 任务成本直接降低约 60%，在主流 Agent 基准评测中紧随欧美顶尖模型，位列国内榜首（来源：[Alibaba Cloud / Yotta Labs](https://www.yottalabs.ai/post/qwen-4-max-specs-benchmarks-pricing-how-to-access)）。
- **Google 发布 Gemini Decisions API 与专用模型 Gemini Decision 1**：谷歌于 11 月 17-18 日面向开发者推出了全新的 Gemini Decisions API 和专用微模型 `gemini-decision-1`。该模型一改传统的 token 生成模式，不输出文本，专门用来在 Yes/No、单选、Rubric 多维度评分等封闭式决策任务中提供概率与置信度。其处理 100万 输入 Token 仅需 $0.10，且无输出 token 计费，这让高并发、超大规模的 Agent 决策筛查成本呈现断崖式下跌（来源：[Google Cloud / shattered.io](https://shattered.io/gemini-decision-1-decisions-api-1000-questions-0-10-per-million-2026/)）。
- **微软在 Ignite 2026 宣布多项 AGI 软硬件升级并推出 Copilot Fusion**：微软年度 Ignite 2026 大会于 11 月 17 日开幕，CEO Satya Nadella 明确表示自己是“AGI-pilled”，并推出其迄今为止最重磅的 AI 开发者平台 Copilot Fusion，将开发工具从单一的代码补全全面升级为内嵌在 VS Code 中的多 Agent 深度协同引擎。硬件方面，微软正式商用自研 Cobalt 200 处理器虚拟机，并发布本地小型语言模型运行层 MAI Code 2（来源：[Microsoft Ignite / Tech Pulse Daily](https://techbytes.app/tech-pulse-daily/2026/november/18/)）。
- **法机器人独角兽 Genesis AI 斩获 $5.0 亿美元巨额 A 轮融资**：主打机械手通用工业机器人的 Genesis AI 宣布完成 5 亿美元的 A 轮融资，投后估值直飙 35 亿美元。本轮融资由 Premji Invest、Khosla Ventures、Eclipse 共同领投，英伟达（NVentures）、AMD Ventures、三星 Next、Ericsson Ventures 及前谷歌 CEO Eric Schmidt 等顶级芯片厂商及个人联合参投。所得资金将主要用于其带传感器手套的 Eno 工业机器人规模化量产（来源：[TechCrunch / QZ](https://qz.com/genesis-ai-500-million-funding-nvidia-valuation-111726)）。
- **多国政府联合签署《旧金山宣言》协同 AI 供应链安全，美方对华算力限制再加码**：美国联合澳大利亚、印度、以色列、日本、韩国、新加坡、阿联酋和英国等九国共同签署《旧金山宣言》（San Francisco Declaration），强化在半导体、超级算力和人工智能供应链的安全协同。同时，美国商务部出台最新算力限制规则，进一步封堵海外数据中心和非常规渠道的先进 AI 芯片流动（来源：[InnovationAus / DEV Community](https://dev.to/vuhung16au/australia-daily-ai-llm-briefing-november-18-2026-54pf)）。

## 重要模型 / 产品动态

- **GPT-6.2 Astra & Sol（OpenAI）**：11 月 17 日正式发布（API：`gpt-6.2-astra` 和 `gpt-6.2-sol`）。两款模型在不降低质量的前提下大幅降低了开发者的使用门槛。其中 Astra 的输入/输出价格为 $8.00 / $40.00 每百万 token（比 GPT-6 下降 20%），在 slide 模板契合度、3D 渲染和前端界面开发上性能大幅提升；Sol 价格为 $2.00 / $10.00 每百万 token，定位为更具任务性价比的“全日候 Agent 推理默认模型”（来源：[OpenAI Community](https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531)）。
- **Qwen4-Max（阿里云）**：11 月 16 日正式发布。它是首款基于全新混合专家（MoE）架构的 Qwen4 旗舰模型，支持 1M 上下文和原生多模态视觉。QwenCloud 的 API 价格为 $1.50（输入）和 $4.50（输出）每百万 token，相比 3.8-Max 每任务消耗 token 数量平均减少 50%（来源：[Alibaba Cloud](https://www.yottalabs.ai/post/qwen-4-max-specs-benchmarks-pricing-how-to-access)）。
- **Gemini Decision 1（Google）**：11 月 17-18 日发布。其作为一类独特的非生成式“决策模型”，不通过 text-generation 编写字符，而是专门通过接收用户的 Closed-set（闭集）问题并在 API 中直接输出概率分布，价格低至 $0.10/1M 字符输入，对百万级数据自动化审核和分类效率提供了数量级的飞跃（来源：[Google Developer Blog](https://shattered.io/gemini-decision-1-decisions-api-1000-questions-0-10-per-million-2026/)）。

## 行业观察与商业博弈

- **Neocloud 云算力军备赛：TensorWave 与 OpenAI 签订六年来最大 457MW 算力协议**：新一代算力服务商 TensorWave 宣布与 OpenAI 达成了其历史上最大规模的一笔协议。OpenAI 承诺在未来六年内，向 TensorWave 采购高达 457 兆瓦（MW）的 AI 基础设施算力。这批算力将全部由 AMD 旗下的 Instinct MI455X 显卡和 Helios 算力服务器集群组成，代表着 OpenAI 在大举脱离对英伟达单一硬件平台的完全依赖（来源：[DCD / Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/tensorwave-announces-agreement-openai-deliver-140000669.html)）。
- **企业 AI 采纳面临数据失控：70% 的澳大利亚企业承认在 AI 浪潮中越过了治理红线**：根据富士通（Fujitsu Uvance Wayfinders）的一项最新全球调研显示，有多达 70% 的澳大利亚企业承认，由于当前企业级 Agent 和 AI 工具部署过于仓促，他们正被迫在尚未完善的旧有数据治理框架之外，更宽泛地共享企业敏感数据。这一比例甚至超过了处于 AI 前沿的美国（60%），凸显出工业界在快速采纳 Agenting 自动化与维持数据主权/安全合规之间面临的巨大摩擦（来源：[TechDay Australia](https://te)）。
