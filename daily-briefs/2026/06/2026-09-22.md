- [安全界披露首个 AI 智能体软件供应链重大漏洞 “Plugin4Shell”，引发百万级开发环境静默执行恶意代码的恐慌](https://www.air.security/blog-posts/plugin4shell) - 9 月 17 日，安全公司 AIR Security 披露了一项名为“Plugin4Shell”的零点击远程代码执行（RCE）供应链漏洞，该漏洞影响包括 Anthropic Claude Code、OpenAI Codex、GitHub Copilot 以及 Google Gemini CLI 在内的四大主流 AI 辅助编程工具。漏洞核心源于这些工具在通过 Git 拉取 pinned（指定 commit hash）版本插件时，仅根据 hash 名字进行 checkout 而未对其实际内容进行哈希校验。由于 Git 在分支名与 commit hash 冲突时会优先选择分支名，攻击者一旦控制了插件仓库，即可通过创建与 commit hash 名字相同的恶意分支，在开发者升级或自动更新插件时静默植入恶意代码。由于 AI 智能体通常拥有极高本地文件及云凭证权限，攻击者可直接实现静默控机并窃取企业代码与系统密钥。目前，Anthropic（Claude Code 2.1.179+）和 OpenAI（Codex 0.146.0+）已完成修复，而 GitHub Copilot 仍未修补，Google 则放弃对已被废弃的 Gemini CLI 进行修补，并建议用户迁移至全新的 Antigravity CLI。[[AI coding agents' 0-click RCE flaw could hand attackers keys to the kingdom]](https://www.theregister.com/security/2026/09/17/ai-coding-agents-0-click-rce-flaw-could-hand-attackers-keys-to-the-kingdom/5297335)（发布时间：2026-09-17）
