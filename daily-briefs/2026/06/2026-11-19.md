### 4. 2.4 万亿参数 MoE 旗舰 Qwen4-Max 全球 GA 商业化：将单任务成本大削 60%

阿里巴巴云正式发布了其最新一代旗舰模型 **Qwen4-Max** 的全球 GA 商业化，结束了此前为期数天的 Token 计划限时预览，向全球开发者正式开放 API[[CASRAI]](https://casrai.org/news/alibaba-qwen4-max-general-release-million-token-context-2026)。

- **庞大的网络与稀疏激活**：Qwen4-Max 基于先进的 sparse Mixture-of-Experts（MoE，混合专家）架构，拥有高达 **2.4 万亿的总参数量**[[Alibaba Cloud]](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max?_p_lc=1)。然而，得益于对注意力机制、残差连接以及词嵌入层的全新升级，单次推理每个 token 仅需激活其中的 **710 亿参数**，比上一代旗舰 Qwen3.8-Max 节省了整整 25% 的激活开销，实现“大而不贵”[[Alibaba Cloud]](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max?_p_lc=1)。
- **惊艳的基准评测**：Qwen4-Max 在行业基准 Work360 评测中大获全胜，不仅在 High effort（高强度思维推理模式）下所消耗的 token 比上代减少 35%，更在保持极高性能指标的前提下，将企业单次任务的 **综合平均运行成本降低了 60%**[[Alibaba Cloud]](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max?_p_lc=1)。此外，该模型在 Code Arena 全球真实编码挑战赛中斩获第 6 名的佳绩[[Alibaba Cloud]](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max?_p_lc=1)。
- **规格与国际定价**：Qwen4-Max 支持 **100 万 token 超长上下文窗口**，单次响应最高可输出 393,216 个 token（思考与最终回答共享上限）[[TechTimes]](https://www.techtimes.com/articles/330536/20261112/alibaba-qwen4-max-preview-retires-november-25-no-benchmarks-model-card-price.htm)。在 QwenCloud 上，官方公布的国际版 API 价格为：**输入端 $1.50/百万 token，输出端 $4.50/百万 token**，而由于隐式缓存命中（Implicit Cache Hit）的价格为极低的 $0.075/百万 token[[CASRAI]](https://casrai.org/news/alibaba-qwen4-max-general-release-million-token-context-2026)。

### 6. DeepSeek 重磅发布全套 App API：一键调用深度思考联网搜索与文件读取功能

大模型超级新星 DeepSeek 宣布正式开启 **“全套 App 功能 API 通用发布”**（Full-Suite App API Release），将广受全球千万用户喜爱的 DeepSeek 官方 App 内置的最强功能底层通过 API 全面释出[[CASRAI]](https://casrai.org/news/deepseek-app-capabilities-api-2026)。

- **内置功能参数一键开启**：开发者可以通过在原有的 Chat 接口请求参数中加入特定标识，即可直接在服务器端调用由 DeepSeek 托管并组装的全套顶级工具链[[CASRAI]](https://casrai.org/news/deepseek-app-capabilities-api-2026)。
  - `deepseek_web_search`：一键开启联网实时搜索，支持非思考模式下的来源内联引用。
  - `deepthink_search`：开启在多步骤推理思考（Deep Thinking Mode）过程中自发进行多轮深入、渐进式检索。
  - **File Input**：在请求体中直接传入 PDF、Word、图像等文件的 base64 或链接，由服务端自动完成高精度解析并喂给模型上下文。
  - `deepseek_read_url`：允许直接把多条外部网页链接传入对话，由服务端自动爬取网页主体内容并进行无损 Context 组装。
- **开发与科研复现成本暴跌**：该接口默认由经过精修调优的 **DeepSeek V4.1-Flash**（`deepseek-flash`）大模型作为中枢提供支持，免去了开发者自己在客户端编写复杂的 Agent、网页爬虫及 PDF 文本清洗（OCR/Parser）等多套复杂系统，大幅优化了研究机构对于检索增强（RAG）和多模态实验的复现效率[[CASRAI]](https://casrai.org/news/deepseek-app-capabilities-api-2026)。
