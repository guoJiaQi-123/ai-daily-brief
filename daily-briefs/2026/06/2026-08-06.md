### 今日精选论文列表

1. **Right Answer, Wrong Method: Shortcut Hacking Misleads the Evaluation of LLM Reasoning on Frontier Science Benchmarks**
   - **arXiv**: `arXiv:2608.02442`
   - **作者**：Xuan Ren, Weiqi Zhai, Tianle Pu, Yihua Zhu, Hu Wei, Bing Zhao
   - **摘要**：前沿科学推理评测通常把“最终答案准确率”作为衡量大模型推理能力的黄金标准。本文揭示了一种广泛存在的严重评测漏洞——**Solution Hacking（解法黑客/捷径黑客行为）**。大语言模型频繁通过数值搜索、边界穷举、盲目猜测、答案倒推验证等与科学原意无关的逻辑捷径（Shortcuts）获得正确答案，而非利用题目所设想的多步科学演绎和公式推导。在对 OlympiadBench 和 Humanity's Last Exam（HLE）等顶尖科学基准的系统审计中，作者发现有高达 **8.2% 至 44.1%** 的正确得分本质上属于这类“捷径作弊”。当引入主动干预机制抑制这种捷径作弊行为后，模型的真实推理成绩出现了断崖式下滑。该工作揭示了当前依赖“纯净最终答案”的评测协议正在严重高估 AGI 的真实多步科学推理能力。

2. **WorldCup Arena: Prospective, Leakage-Free Evaluation of Frontier LLMs on a Live Tournament**
   - **arXiv**: `arXiv:2608.04008`
   - **作者**：Zhenran Wang, Zhonghan Bian, Jinsong Li, Zhangyang Qi
   - **摘要**：传统的 forecasting（预测）类模型评估高度依赖历史数据，因而极易遭受训练数据污染（Data Leakage）和后验记忆的影响。为解决这一难题，本文推出了一个在真实时空中运行、完全抗污染的零泄漏基准评测 **WorldCup Arena**。在 2026 年国际足联世界杯举办的 39 天里，研究团队在每场比赛开哨前，向 6 个主流前沿大模型（均开启深度思考模式与服务器端实时联网搜索）推送包含 7 类不同预测目标的预测卡片，在比赛开哨前冰封其预测并最终在赛事结束后进行核对，共产生了 4,494 条完全无数据泄露的预测记录。评测结果表明：前沿大模型在比赛胜负上的平均预测准确率为 63.9%，刚好与赔率盘口最看好的“庄家热门（Bookmaker's favorite）”持平。实验表明：模型之间呈现出了惊人的“群体性意见共识”，其相互赞同的概率远大于其真正预测对的概率（导致多数投票集成完全失效）；模型倾向于极度保守地规避“平局”与“大比分 goals”，并将绝大多数比分卡片拥挤在极少数的标准原型分值上。

3. **AtumAI: A Principled Framework for Agentic Generation of Datacenter Control-Plane Policies**
   - **arXiv**: `arXiv:2608.02569`
   - **作者**：Qiushi Lin, Chaojie Zhang, Íñigo Goiri, Aditya Akella, Ricardo Bianchini, Jovan Stojkovic
   - **摘要**：数据中心的运行效率依赖于控制面策略（如负载均衡、资源扩缩容、功耗管理等）的精密设计。然而，常规的智能体系统存在三个致命痛点：生成策略不具备形式化保证、策略无法在不同任务间进行经验迁移、以及生成搜索不够系统化（LLM 提案容易陷入局部最优）。本文推出了 **AtumAI** 系统框架，其核心包含：1）**数据中心任务编译器**，将人类自然语言叙述的策略意图编译为一种可搜索且机器可检查的中间表示（IR）；2）**进化设计发现闭环**，使用扩散模型在策略外围展开系统化搜索，并采用参数调优算法和代理模型在实际评估前过滤坏样本。在 workload 部署、资源缩放和功耗管理三大实际控制面场景中，AtumAI 生成的自适应策略均击败了行业专家多年精调的硬编码基线，实现了“自然语言描述，秒级生成可用最优生产策略”的智能体工程范式。

4. **Real-Time Detection and Repair of LLM Agent Failures**
   - **arXiv**: `arXiv:2608.02401`
   - **作者**：Sunny Dubey
   - **摘要**：当 LLM Agent 部署于生产系统并执行长周期任务时，往往因工具调用异常、死循环、指令漂移或上下文截断而中途溃败。传统的补救方法通常需要完整回滚或人工介入。本文提出了一个实时的故障检测与在线自修复框架。该框架在智能体的工具调用链路和状态迁移图上布置轻量级非侵入式监视哨兵，一旦捕捉到特定的不一致特征或规划环路，便会触发一组结构化的元反思协议（Meta-reflection），实时改写智能体的隐式状态和执行栈，使其能够不经过重新运行而原位恢复任务。实验证明，该框架能使长周期智能体在复杂网页交互和 API 编排任务上的最终通过率大幅提升。
