## 今日重要模型 / 产品发布

### 今日模型发布

* **OpenAI 发布生物学与药物研发专用大模型 GPT-6 Rosalind**：
  - OpenAI 正式向少数受信任合作伙伴推出了 GPT-6 Rosalind 研究版。该模型复用了 GPT-6 Astra 这一代旗舰级模型的底层权重，但特别针对双用途（Dual-use）的生物化学及药物研发布置了豁免安全拒答通道。
  - 在内部基准测试中，GPT-6 Rosalind 展现出了惊人的垂直突破，在药理化学基准 MedChemBench v7 上准确率由 28.9% 飙升至 49.6%，并在生命科学综合评测 LifeSciBench Gold 上达到了 61.3%[[AI News Today, November 1: Top Stories | AI Weekly](https://aiweekly.co/ai-news-today)]。

* **DeepSeek 震撼开源其超级编程智能体 Super-agent 原型**：
  - 10 月 31 日，DeepSeek 团队向 GitHub 正式开源了其最新的全自动化编程助手 Super-agent（基于 MIT 开源协议）。该项目在发布 24 小时内便斩获了超过 4,000 颗 GitHub 星标。
  - Super-agent 与 Anthropic 的电脑端控制及 Claude Code 形成直接竞争，支持直接监听 GitHub 仓库甚至企业飞书群聊，利用内嵌的 Router/Worker 弹性并行工作流，自主发现、拆解并提交高质量 Pull Requests[[AI News Today, November 1: Top Stories | AI Weekly](https://aiweekly.co/ai-news-today)]。

* **Vercel 发布 agent-desktop 开源库，实现免屏幕截图的底层“电脑操作”**：
  - 前端部署巨头 Vercel 开源了 agent-desktop（Apache-2.0 协议，支持 Rust 和 C）。它并不像传统的 Agent 采用高开销的系统截图来理解用户屏幕，而是通过直接读取操作系统的原生可访问性树（macOS AX API / Windows UI Automation / Linux AT-SPI）。
  - 在实际测评中，该方法可使复杂的 52 步自动化任务消耗的上下文 Token 数量从 19.8 万暴降至 3.1 万[[AI News Today, November 1: Top Stories | AI Weekly](https://aiweekly.co/ai-news-today)]。
