## 今日重要模型 / 论文

### 今日重要论文

- **Apodex 1.1：突破轻量化模型长周期工作极限（arXiv:2608.23283）**：
  论文提出了一种针对复杂、长运行、需要多工具协调之工作任务（Working Capability）的 Agent 架构[[Apodex 1.1: Scaling Agentic Intelligence for Complex Work - arXiv](https://arxiv.org/abs/2608.23283)]。通过引入 **环境缩放（Environment Scaling）** 扩充可执行的代码、搜索、文件系统边界，以及 **智能体协同缩放（Agentic Coordination Scaling）** 训练多智能体分工，Apodex 1.1 使得一个 35B 参数规模的轻量模型在金融、科研、代码、重度搜索任务上的解决率跻身第一梯队，证明了无需盲目追求千亿参数，通过特化操作系统级架构设计（AgentOS）即可显著提升 Agent 工作效能[[Apodex 1.1: Scaling Agentic Intelligence for Complex Work - arXiv](https://arxiv.org/abs/2608.23283)]。
- **Paritok-4B：为 Coding Agent 打造的高保真上下文 extractive 压缩模型（arXiv:2608.24188）**：
  长周期的 Coding Agent 每次执行 tool call 都需要将前序长代码和日志发给大模型，这造成了极高的 Token 成本，普通文本压缩极易破坏代码语法、修改变量名。Paritok-4B 创新地提出了**抽取式（extractive）且由意图引导（intent-conditioned）的上下文压缩方法**[[Paritok-4B: Intent-Conditioned Context Compression for Coding Agents - arXiv](https://arxiv.org/abs/2608.24188)]。其在 OpenHands 包含 67,000 条轨迹的数据上进行知识蒸馏，训练了一个 4B LoRA 压缩器。在 SWE-bench 评测中，成功将上下文长度压缩至原先的 25.7%（压缩了近 4 倍），同时完美保留了 96% 的变量、路径与标识符，且下游 Agent 最终的代码 Bug 解决率依旧能保持在 uncompressed 状态的 86.5%，极大地降低了端侧 Agent 部署成本[[Paritok-4B: Intent-Conditioned Context Compression for Coding Agents - arXiv](https://arxiv.org/abs/2608.24188)]。
- **通过多轮写作轨迹逆向重构，大幅提升 CPT 预训练效果（arXiv:2608.25826）**：
  该研究提出了一种将高质量科学论文重构为“教师模型构思写作过程”的逆向生成轨迹方法（全局计划、每章节的前置思考等），并将原本论文的文字 verbatim 嵌入其中，得到两倍于原文本长度的 Continued Pre-training (CPT) 语料[[Unfolding Scientific Papers into Multi-Turn Generation Trajectories for Continued Pre-Training - arXiv](https://arxiv.org/abs/2608.25826)]。在 arXiv 论文集上的微调测试表明，这种带有“思维轨迹过程”的预训练，不仅大幅提升了下游模型的学术写作和长文本阅读理解能力，且完全没有损害其通用推理基准[[Unfolding Scientific Papers into Multi-Turn Generation Trajectories for Continued Pre-Training - arXiv](https://arxiv.org/abs/2608.25826)]。
