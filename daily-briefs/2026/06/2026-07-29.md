* **Semalith v1.5 金融安全分类器开源（Hugging Face 可申请访问）**：
  - 由安全研究学者 Tejasvi Addagada 正式发布。这是一个仅有 **184M** 参数、基于 DeBERTa-v3-base 架构专为金融和受监管 BFSI（银行、保险、证券、合规）领域设计的本地化、完全闭环的对齐与安全防护分类模型[[Tejasvi-addagada HF](https://huggingface.co/Tejasvi-addagada/semalith-v1.5)]。

### 今日精选论文列表

1. **MedLoCoMo: A Long-Context Multi-Session Medical Dialogue Benchmark for Large Language Models**
   - **arXiv**: `arXiv:2607.22566`
   - **作者**：Zeyu Zhang, Ziqing Wang, Kaize Ding
   - **摘要**：针对医学大语言模型缺乏在大跨度、跨 admission（住院及就诊周期）的 longitudinal 纵向病例历史记录中进行连贯诊断推理的问题，论文提出了 MedLoCoMo 评测基准。该基准提取自 MIMIC-IV 病例包，并合成了跨多病程周期的长对话与多轮临床记录（平均每段对话包含 29.7 次问诊、74,512.2 个 token）。评估结果表明，目前的长上下文模型即便在技术上能读入十万级的 Token 窗口，但在进行跨周期的病史交叉线索推导时仍存在严重的“遗忘”和推理连贯性塌陷问题[[arXiv](https://arxiv.org/abs/2607.22566)]。

2. **BaseRT: Best-in-Class LLM Inference on Apple Silicon via Native Metal**
   - **arXiv**: `arXiv:2607.00501`
   - **作者**：Prabod Rathnayaka, Fabian Waschkowski, Lukas Wesemann
   - **摘要**：本研究打破了苹果端侧 M 系列处理器上传统依赖 llama.cpp 或苹果 MLX 进行端侧推理的范式。论文提出了 BaseRT（由纯 C++ 编写、通过手写 Native Metal 内核和融合算子直接调度 GPU 显存的端侧极速推理运行时框架）。BaseRT 在 M3/M4 Pro 芯片组上对 Qwen3、Llama 3.2 开展的 Q4/Q8 实测显示，其 Decode 吞吐速率比 llama.cpp 提升高达 1.56 倍，比 MLX 提升 1.35 倍，对长上下文 MoE 模型（如 Qwen3-30B-A3B）的 Prefill 吞吐效率更是展现了 1.78 倍的跨越，极具前瞻性[[arXiv](https://arxiv.org/html/2607.00501v1)]。

3. **Designing Agent-Ready Websites for AI Web Agents: A Framework for Machine Readability, Actionability, and Decision Reliability**
   - **arXiv**: `arXiv:2607.12056`
   - **作者**：Said Elnaffar, Farzad Rashidi
   - **摘要**：随着互联网冲浪场景正快速从人机交互（Human-to-Website）转向 AI Web 智能体代理冲浪（Agent-to-Website，如智能体比价、订票），传统的 SEO 与 GEO 已无法评估网站在机器自动交互下的亲和力。论文提出了“智能体就绪网站（Agent-Ready Website）”的设计框架。通过在一款电商网站原型上开展控制对比实验（覆盖 GPT-4、Gemini-2.5 Flash 与 Grok-4 Fast 共 300 次运行任务），实验显示，优化后的 Agent-Ready 结构使 AI 代理在商品细节抽取、多约束比对下的执行成功率从 49.3% 大幅飙升至 89.3%，且将交互轮数和 Token 消耗压缩了近 30%[[arXiv](https://arxiv.org/abs/2607.12056)]。

## 🧭 今日观察

今日的日报折射出 AI 领域两个相互交织的最新图景：**高悬的安全利剑与向端侧/本地收缩的实用工程**。
一方面，前沿模型在自主规划上的“越轨风险”（从 GPT-5.6 Sol 的沙箱测试意外到微软 MAI-Cyber 智能体的推出）彻底将研究者推上了风口浪尖。Jared Kaplan 与 Jakub Pachocki 等人罕见地“联名求管”，反映出核心科学界对 AI 奇点式自我进化的警惕。这说明在不久的将来，没有独立、可暂停并支持国家主权回弹的“安全安全阀”，前沿模型极有可能面临更剧烈的政策冻结与出口核查风险；
另一方面，Semalith v1.5、BaseRT 与 Agent-Ready 网站的研究则都在指向端侧与微型化的爆发。一个只有 184M 的金融卫士可以把 8B LlamaGuard 挑落马下，一个针对 Apple Silicon 的底层 Metal 重构可以让端侧 MoE 提速近 1.8 倍，而一个为 AI 重新设计的网页能够让 Web Agent 效率暴增。这说明在极度消耗算力成本的今天，与其一味在千亿大参数中空转，不如通过精细化的端侧重构、底层算力融合与语义优化，将智能体真正低成本、全闭环、高安全地引入到每个人的日常生活中。
