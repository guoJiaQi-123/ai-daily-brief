### 今日精选论文列表

1. **ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction**
   - **arXiv**: `arXiv:2607.29677`
   - **作者**：Boyang Zhang, Adrian Lyjak, Eli Stewart, Zhaoqi Li, Simon Suo
   - **摘要**：企业文档信息抽取（Information Extraction）通常受到目标模式（Schema）复杂性和文档结构多样性的制约。本文推出了 **ExtractBench**，一个专注于 Schema 引导的现代企业级大型文档提取基准测试[[Artificial Intelligence](https://arxiv.org/list/cs.AI/recent)]。其包含大量真实工业界的高度非结构化文档（包含各种表格、多层嵌套关系以及长尾特定文本），用以系统化评估大语言模型与多模态模型对特定Schema规则的理解深度、约束一致性输出以及复杂拓扑结构的捕捉精度，为衡量企业级大模型应用落地提供了全新的高难度测试床。

2. **CAGE: Certified Authorization under Typed-Return Uncertainty for Tool-Using Agents**
   - **arXiv**: `arXiv:2607.29190`
   - **作者**：Blaise Delattre, Cong Wang, Yang Cao
   - **摘要**：当 LLM Agent 具备调用外部工具与 API 的能力时，系统安全性面临极大的不确定性，尤其是在返回结果的类型和内容不可预测的情况下。本文提出了 **CAGE**，一个在类型返回不确定性下对工具调用 Agent 进行“认证授权”（Certified Authorization）的安全框架[[Artificial Intelligence](https://arxiv.org/list/cs.AI/recent)]。该框架通过引入静态类型约束、动态执行沙箱以及状态转移概率证明，实现了对 Agent 行为轨迹的边界认证，使得即使在遭遇恶意的外部工具注入或返回欺骗时，Agent 的执行流依然能被严格约束在预设的安全合规红线之内。

3. **MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations**
   - **arXiv**: `arXiv:2607.28956`
   - **作者**：Qiming Shi, Yulong Tao, Linbo Jin, Zhaolu Kang, Yibo Dou, Jiawen Zhu, Tianjun Pan, Shaokang Fu, Chengyu Wang, Siyue Li, Yaping Cheng, Di Weng, Chengfu Huo
   - **摘要**：将大模型部署为电商运营 Agent 需要其在处理长周期、多步骤、受限策略交互的任务中维持长期的行为连贯性（Long-term Coherence）。本文推出了 **MerchantBench**，用于多维度评测 LLM 智能体在面对极长历史、动态反馈、供需多变及突发客户舆情等真实商业链路场景下的多轮策略优化能力[[Artificial Intelligence](https://arxiv.org/list/cs.AI/recent)]。基准对目前主流的开源与闭源前沿模型进行了详尽分析，指明现有 Agent 框架在面对“长期状态维持”与“战术灵活调整”的平衡时仍面临较大退化瓶颈，并指明了下一代主动决策式商业 Agent 的优化方向。
