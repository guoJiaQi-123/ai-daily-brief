2. **OpenAI 推出 GPT-6 Cyber 安全模型，网络安全风险评估上调至最高级 "Critical"**：OpenAI 近日（11-05）正式发布 GPT-6 Cyber 并在今日引发网络安全界强烈反响。该模型专为漏洞发现与验证对齐训练，在 ExploitGym 漏洞利用基准上取得 48.5% 评分（相比 GPT-5.6 Cyber 的 32.1% 相对提升 51%）。GPT-6 Cyber 在实际测试中曾帮 Mozilla 找出 81 个 Firefox 高危漏洞，在 Linux 中成功复现 1,724 个漏洞并对其中 948 个完成漏洞利用验证。因此 OpenAI 在其《备灾框架》中将该模型网络安全风险等级评定为最高级别 "Critical"（临界），目前仅限受限的 "Daybreak Red" 计划安全团队通过 API 与 Codex 闭门使用，并配有 Private Safety Processing（PSP）等加密审查审计手段。[[The Register]](https://www.theregister.com/security/2026/11/05/openai-releases-gpt-6-cyber-and-promises-this-one-stays-within-rules-of-engagement/5307855)
3. **猫王（Elvis）遗产机构与埃米纳姆（Eminem）出版商起诉 AI 音乐生成巨头 Suno 侵权**：2026-11-06（11-09 媒体集中建档披露），Elvis Presley Enterprises 与 Raleigh Music Publishing 联合、以及 Eminem 的核心曲库管理商 Eight Mile Style，向加州北区联邦地方法院针对 Suno 分别发起全新侵权诉讼。Eight Mile Style 诉状指出 Suno 侵权使用 269 首 Eminem 词曲进行训练，索赔金额超 4000 万美元；猫王版权方则首次援引田纳西州 2024 年颁布的《ELVIS法案》（防止未经授权的声音克隆），起诉 Suno 即使在输入过滤屏蔽了 "Eminem" 或 "Elvis" 后，用户通过插入空格（如 "E m i n e m"）或其真名仍能轻而易举绕过限制克隆其声音及利用其姓名。[[CSO Online]](https://www.csoonline.com/article/4244911/openais-gpt-6-cyber-ups-the-ante-on-vulnerability-discovery.html)
4. **Franklin Templeton（邓普顿）使用 OpenAI 代理和语义层重塑投资研究流程**：2026-11-05（近日入档更新），老牌资管巨头 Franklin Templeton 宣布通过将 OpenAI 模型、自主 Agents 架构与专有的“语义层”结合，重塑其股票投资研究流程。该语义层建立了企业内部数据关系与规范，解决了传统 RAG 架构大模型对孤立数据库无法理解关联的弊病，使基金经理能够快速对比不同研究报告与审阅投资风险。[[OpenAI]](https://openai.com/index/franklin-templeton/)

### 今日模型/产品发布

* **OpenAI 联合 Ligo 发布 BioBasicsBench 湿实验 AI 评估基准**：2026-11-06，OpenAI 联合酶设计生物技术公司 Ligo 发布了 "BioBasicsBench"，这是一套包含 100 项真实实验室日常湿实验分析任务的数据集。该基准专门用来评估 AI Agents 在生物信息学、解释原始实验数据（如凝胶图像、菌落板、显微镜数据及仪器读数）方面的能力。测试表明，OpenAI 最强推理模型 GPT-6 Astra 获得了 66.7% 的评分，GPT-6.1 Sol 获得 62.0%，而上一代 GPT-5.6 Sol 仅有 43.8%。Astra 展现了对复杂图像和实验的高度分析力，但研究也指出其存在 colony-PCR 选错条带导致提出错误质粒设计等方向性逻辑错误。[[OpenAI]](https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science/)
* **AI Engineer Code Summit 2026 在旧金山隆重召开**：2026-11-10，第二届年度 AI 程序员峰会（AIE CODE Summit）在旧金山联合广场希尔顿酒店正式开幕。会议将持续至 11 月 12 日，重点探讨对抗软件工厂的“废话代码”（Fighting Slop）、使用 System One 推理模型以及批判性应用重构三大主题。Google DeepMind 后训练负责人 Melvin Johnson、TypeSafe AI 联合创始人 Diogo Almeida、Anthropic 的 Jarred Sumner 携手进行开幕 Keynotes 演讲，分享前沿工程落地规范。[[AIE Code Summit]](https://ai.engineer/code/2026)
