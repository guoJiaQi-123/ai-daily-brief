## OpenAI DevDay 2026

### dots：24/7 常驻智能体

dots 由 GPT-6 Astra 驱动，每个 dot 拥有独立的云端计算机与浏览器，用户可随时打开其云端电脑检视工作过程；通过插件生态可连接 4000 多个应用，触达渠道包括 ChatGPT 桌面端、网页端、移动端以及 Slack 和 Teams，短信通道即将上线，上下文可跨渠道保持。::cite[9370]

安全机制方面，用户未主动交互时的“主动研究”仅使用只读工具，不能发送消息、修改应用内容或操控浏览器；改密码等敏感操作始终保留给用户本人，其他可能影响账户或分享信息的动作经由 auto-review 判定放行或弹出审批，监控系统发现风险可暂停或中止 dot。::cite[9370]

dots 首先面向 Pro 与 Business Premium 用户在符合条件的市场推出，Enterprise（含教育、医疗）可由管理员启用 Beta；首个 dot 包含在套餐内，但其发起或管理的 Codex、ChatGPT Work 任务仍按规则计入使用额度，初期每名用户仅可创建一个 dot。::cite[9370]

### GPT-6.1 Sol：五分之一价格的近旗舰能力

GPT-6.1 Sol 是 GPT-6 Sol 的升级版，在智能体编程、电脑操作和专业工作上逼近 GPT-6 Astra；标准 API 定价为每百万 token 输入 2 美元、输出 10 美元，缓存输入 0.10 美元，缓存价较 GPT-6 Sol 低 50%。::cite[9371]

基准表现方面，DeepSWE v1.1 软件工程评测与 Astra 持平，在更低推理强度与成本下比 GPT-6 Sol 最佳成绩高 6.4 个百分点；OSWorld 2.0 离线集比 GPT-6 Sol 高 7 分、距 Astra 仅 2.1 分；Terminal-Bench Science 0.1 单任务平均成本 5.47 美元，而 Opus 5.5 为 23.21 美元、Astra 为 23.80 美元；低推理强度下事实错误率从 11.4% 降至 7.7%。::cite[9371]

当输入超过 272,000 token 后，输入单价升至 4 美元、输出升至 15 美元；GPT-6.1 Sol 今日起在 ChatGPT Work 和 Codex 面向 Plus、Pro、Business、Enterprise、Edu 用户开放（暂不进入 Chat），API 模型名为 gpt-6.1-sol，数日内还将支持最高 8 倍速的 Ultrafast。::cite[9371]

### ChatGPT Space、Codex 上云与商业化更新

ChatGPT Space 是面向团队的协作空间，用户、同事与智能体围绕共享文档协同工作，Pages 文档支持人机共同编辑并随数据源自动更新，协作式幻灯片可导出 PowerPoint 或 Google Slides；在 Slack 和 Teams 中可直接 @ChatGPT，完成群聊简报、缺陷排查与客户动态汇总。::cite[9402]

Codex 全面支持云端运行：用户可从手机发起任务，再通过浏览器或桌面端接续，即使关闭电脑，智能体仍可在云端继续工作；新推出的 Codex Security Cloud 可按需或定时扫描 GitHub 代码仓库。::cite[9374]

订阅与生态方面，新增 500 美元/月的 Pro 500 套餐，额度为 ChatGPT Plus 的 25 倍，包含 GPT-6 Astra Ultrafast（Codex 中生成速度最高约 300 tokens/s、8 倍于标准速度）；200 美元 Pro 套餐重新开放并调整使用额度；“使用 ChatGPT 登录”功能向第三方开放，OpenAI 软件市场首批 32 家合作伙伴包括 Adobe、Figma、Salesforce、ServiceNow、CrowdStrike 等。::cite[9430]

### Anthropic：GLM-5.3 高级网络能力扩散报告

Anthropic 前沿红队报告称，智谱 GLM-5.3 具备与五个月前限量发布的 Claude Mythos Preview 类似的端到端漏洞利用构建能力，却未配套有意义的防护：在基于 Chrome V8 的 ExploitBench 上，GLM-5.3 在 410 次尝试中 50 次构建出端到端利用（约 12%），Claude Mythos Preview 为 56 次；研究员在沙箱中用 GLM-5.3 于一天内链接多个此前未知的浏览器漏洞、实现访客任意文件读取，相关漏洞已向维护者披露。::cite[9433]

防护绕过测试中，谎称是演练中的自主红队代理可使模型 64% 响应恶意请求，预填思考内容使比例升至 92%，开源权重经标准 abliteration 技术去除拒答后达 100%；Anthropic 团队自测 abliteration 约耗 2200 GPU 小时、成本约 4400 美元，模型在三项有害请求测试上的拒答率从 90% 以上降至 3%、2% 和 12%，而 GPQA-Diamond 科学能力分数保持不变；同样三种手法对受防护的 Claude 模型均未成功。::cite[9439]

同日 Anthropic 还启动“What Do You Want from AI?”公众研究项目，使用 Anthropic Interviewer 收集公众在工作、学校、医疗和政府场景中的 AI 体验与意见。::cite[9363]

## 今日 arXiv 精选

- **Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning**：论文提出由 controller 显式推理“接着做什么、要不要重来、何时停止”、workers 执行具体任务的智能体 harness；在长程程序重建基准 ProgramBench 上，GPT-5.5 取得 71.5%（Codex 为 58.0%），Opus 4.8 为 67.2%（Claude Code 65.5%），三个前沿模型平均比直接控制高 3.6–4.2 分。::cite[260938147]
- **Learning Meta-Skills for Agent Harness Design in Test-Time AI4AI**：在模型权重全部冻结的前提下，让 Builder 从执行反馈中学习“何时需要支撑、提供什么资源”的 Meta-Skill 原则，再为未见任务构建执行环境；在 Harness-Bench 与 NewtonBench 上宏平均性能比无技能构建高 8.95 分、比直接把资源库交给 Target 高 12.02 分。::cite[260938143]
- **Do LLM Agents Execute the Plans They Declare?**：论文定义“计划声明—执行差距”，发现通用 Plan+ReAct 只有 22–45% 的轨迹保持了声明的计划结构，而模式专属执行器在 ALFWorld 上把成功率从 0.48 提升到 0.92、在 SWE-bench Verified 上从 0.36 提升到 0.44。::cite[260938108]
- **Correct Answers, Invalid Traces**：在可逐步程序化校验的 iGSM 小学数学基准上，最难样本中 31.6% 的正确答案伴随无效思维链，其中半数以上通过全部语法与算术检查、却不满足语义依赖；打乱 10% 训练 trace 仍能保持接近干净的准确率，提示思维链不能被直接当作真实推理记录。::cite[260938107]
- **KV-Kaizen**：论文让选择器在预填充前根据上下文为每层指定缓存深度、精度与低秩秩数的组合，在不驱逐 token 的情况下压缩 KV cache；14B 模型长上下文任务实现 32 倍解码缓存缩减且保持精度，7B 以上模型 4 倍缓存缩减无精度损失。::cite[260937988]
- **Mira: Memory-Efficient MoE Inference**：面向单 GPU 跑 MoE，论文用轻量预测器提前两层预判专家使用并主动预取，配合两级 HOT+STAGE 缓存与定制量化，在显存受限 GPU 上平均吞吐提升 5.71 倍、首 token 时间缩短 11.71 倍。::cite[260938090]
- **The Unequal Influence of Bad Advice**：论文用训练数据归因量化每条有害样本对“涌现性错位”的贡献，按归因分数过滤数据可显著增强或削弱错位行为，并验证归因分数在三个模型家族间具有部分跨模型泛化能力。::cite[260937914]

## 今日观察

1. **“执行环境”正在成为与模型权重同等重要的竞争维度**：dots 的独立云端电脑、Meta-Skills 的 harness 构建、Planning-as-Routing 的模式专属执行器与 DeepSeek Harness 桌面版共同指向一件事——智能体差距不只在模型分数，计划能否被忠实执行取决于环境如何被设计。
2. **安全治理出现明显路线分叉**：一边是以更名行政令和无罚则自律协议为代表的“企业自我监管”路线，另一边是 Anthropic 用实测数据公开标注开源旗舰模型的防护缺口；高级能力向可下载权重扩散的速度，正在超过治理工具的建设速度。
3. **推理成本继续坍塌，应用层进入“单任务 ROI”精算期**：GPT-6.1 Sol 把专业任务成本压到旗舰的五分之一至七分之一，KV-Kaizen 与 Mira 又从缓存、专家调度等系统侧压缩开销，应用公司的核心能力正从“调用最强模型”转向“以最低可靠成本交付任务”。
