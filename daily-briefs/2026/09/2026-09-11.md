## 模型、平台与开发者生态

- **第三方报道 / 待官方确认：OpenAI Agents API 进入公测**：今日多家媒体报道称，OpenAI 已把支撑 Codex 与企业版 ChatGPT 的托管 Agent 执行框架对外开放为 Agents API，开发者可通过一次 API 调用指定任务、模型、工具与运行环境来创建生产级智能体，计费仍以模型 Token 和工具调用为主::cite[6195].

## 企业应用、终端与产业动态

- **Tata Elxsi 宣布战略投资 KAVIA AI**：PR Newswire 今日发布的官方稿件显示，Tata Elxsi 已对企业级 AI 平台公司 KAVIA AI 进行战略投资，双方将继续围绕复杂软件环境现代化和 AI 驱动的软件工程自动化展开合作::cite[6154].
