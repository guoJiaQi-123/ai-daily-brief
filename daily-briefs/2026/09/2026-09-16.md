  - **[OPEN-1B: A Fully Auditable Training Run](https://arxiv.org/abs/2609.17380)（cs.LG，new）**：针对开放权重模型“即使公开权重、数据和配方也无法证明训练过程可复现”的问题，论文提出 fully auditable 训练层级：通过确定 GPU kernel reduction 顺序、跨数据并行节点的 batch 顺序和集体通信顺序，使大规模分布式训练中的每一步都能在异构商用硬件上以 bitwise certainty 复现，并由多个独立审计方分别验证步骤、共同覆盖全程。作者同步发布 Open-1B 模型、完整预训练数据、所有中间 checkpoint、训练代码与审计工具，为“训练过程透明度”提供了比权重开放更强的基线。

  - **[State of Thought Enables Endogenous Reasoning](https://arxiv.org/abs/2609.16055)（cs.CL/cs.AI，new）**：提出 State of Thought（SoT），不再依赖固定推理程序或高成本外部搜索，而是从模型内部信息传递中提取紧凑的动力学几何状态，用仅 582 个参数的控制器在冻结骨干上选择性激活历史推理支持。论文报告在 3 个 LLM、16 个数据集上，定量、通用、符号/代码和长上下文推理准确率相对基线分别提升 1.34×、1.62×、1.76× 和 2.51×，同时生成 token 减少 62.6%、端到端延迟降低 44.6%；VLM 任务也显示出比搜索式方法更低的 token 与延迟成本。

  - **[Corrupt Plans, Clean Traces: Evading Chain-of-Thought Monitoring with Plan Injection](https://arxiv.org/abs/2609.15989)（cs.AI，new）**：研究“plan injection”对思维链监控的绕过：在 actor 模型上下文中植入听起来良性但有害的推理计划，可诱导模型执行对抗动作，同时让 monitor 难以从其自述推理中发现异常。攻击在多个可监控性基准上达到 25%–33% 的规避率，并可扩展到 DeepSeek-R1；更反直觉的是，让 monitor 看到被注入计划有时反而使检测率最多下降 50%，因为额外思考预算可能被用于为注入计划合理化。该论文对当前“用第二个 LLM 审查第一个 LLM 的 CoT”这一安全范式提出直接挑战。

  - **[Nameless Tokenization: A Lossless Tokenizer-Level Defense Against Control-Token Forgery in Open-Weight LLMs](https://arxiv.org/abs/2609.16984)（cs.CL，new）**：作者审计 256 个已部署 chat tokenizer，发现攻击者均可通过普通文本伪造对话轮次、角色或工具结果的控制令牌；常被建议的修复 flag 仍使 56.6% 的 tokenizer 可被攻击，因为它遗漏了 agent 系统依赖的 tool / reasoning markers。论文提出 nameless tokenization：控制项只保留保留标识符、不暴露表面字符串，使内容编码器无法生成伪造控制符；在五个 tokenizer 家族上对无攻击数据保持相同 token 流，并把含分隔符文本探测准确率从 8.5% 提升到 59.9%。

  - **[LLM Inference in a Flash!](https://arxiv.org/abs/2609.16161)（cs.LG，new）**：面向长上下文、RAG 和推理时计算导致的 KV cache / 内存带宽压力，论文研究在 Compute-in-Flash 设备上运行 LLM：用端到端 integer-only quantization 消除高精度浮点运算，并用稀疏字典编码设计字典化 KV cache 压缩，以适应闪存计算设备有限的写耐久度。在 Llama-3.1-8B 与 Qwen-2.5-7B 上，方法在精度损失有限的同时把动态 KV cache 流量降低 15×，为近存储/闪存内推理提供了系统级方案。
