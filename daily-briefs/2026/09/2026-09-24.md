## 一、今日要闻

### 1. Anthropic 官宣：Claude 在新生物实验室"自主发现"类 CRISPR 酶系统
Anthropic 官方发布文章《Claude discovers a novel enzyme system》，介绍其 2026 年春组建、位于旧金山湾区的生命科学研究团队与湿实验室（BSL-1/BSL-2 级，不处理人类病原体）的首批成果：Claude 在科学家仅给出高层方向的情况下，从大规模 DNA 序列数据中识别出一个此前未被完整描述的酶系统，其附近存在长段重复 DNA 序列，结构特征令人联想到 CRISPR::cite[8590]。

- 该系统被命名为 **ART（array-associated reverse transcriptases，阵列相关逆转录酶）**，包含逆转录酶基因、附属基因与重复 DNA 序列；计算筛选由约 **950 个 Claude agent 并行工作 21 小时、处理 2.1 亿 token** 完成，从噬菌体（感染细菌的病毒）DNA 中筛出候选::cite[8593]。
- Anthropic 同时强调：该酶系统的**功能尚未得到实验证实**，也还不能与可编程 DNA 编辑建立联系，模型生成的候选不等于经过验证的发现::cite[8590]。
- 市场反应：消息公布当日，基因编辑概念股普跌，CRISPR Therapeutics 跌 5.54%、Beam Therapeutics 跌 6.02%、Prime Medicine 跌 11.58%（第三方行情数据）::cite[8561]。
- CEO Dario Amodei 借此表示"AI for biology 正处于类似 2023 年大模型能力起飞的指数趋势上"，但实验室验证仍需数周，且不会缩短临床试验周期（第三方报道 / 详见官方原文）::cite[8590]。

### 2. 千问当日发布 Qwen-Audio-3.1 系列语音大模型，全线 API 价格最高下调 95%
在今日（9 月 24 日）的云栖大会上，千问正式发布 **Qwen-Audio-3.1 系列**语音大模型，对语音识别（ASR）、语音合成（TTS）与实时语音交互（Realtime）三大核心模型全面升级，并新推出音频创作模型 **Qwen-Audio-3.1-TTS-Next** 与音频理解模型 **Qwen-Audio-3.1-ASR-Next**；系列全线 API 价格最高下调 95%::cite[8605]。

界面新闻同日上午的报道确认了该系列的发布，并指出生产力 Agent 正成为 AI 发展的重要方向::cite[8585]。
