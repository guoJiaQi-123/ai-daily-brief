## 官方动态与企业新闻

- **OpenAI 官方宣布 GPT-5.6 Sol API/积分降价超 20%**：OpenAI 社区公告（2026-08-22）显示，未来三个月将前沿模型 GPT-5.6 Sol 的 API 与积分定价下调超过 20%，标准短上下文输入价由每百万 token 5 美元降至 4 美元、输出由 30 美元降至 20 美元，覆盖 API、ChatGPT Work 与 Codex 积分，路透社称此举意在应对 Anthropic 与中国模型的竞争。::cite[4232]

- **据科技媒体报道，OpenAI 全面开源 Codex 底层框架 Harness**：93913 等媒体 8 月 22 日报道，OpenAI 将驱动 Codex 的底层 Agent 执行框架 Codex Harness 开源，包含自动化命令行工具、开发者工具包与应用服务端三模块，开发者可将 OpenAI 级别的智能体循环整合进自定义业务面板；有分析将其解读为竞争从“模型层”向“运行时/编排层”延伸。::cite[3789]

- **第三方报道 / 待官方确认：Anthropic 拟本月递交 IPO 招股书，目标估值约 2 万亿美元，将“AI 与数据中心舆论反弹”列为风险**：多家媒体 8 月 22 日援引知情人士称，Claude 开发商 Anthropic 计划本月提交上市申请，目标估值约 2 万亿美元、有望超越 SpaceX 创下的募资纪录；其招股书拟把公众对 AI 及数据中心扩建的负面情绪作为重大风险因素，并已在旧金山与银行家和投资者进行“试水”会议。::cite[4252]

- **第三方报道 / 待官方确认：Anthropic 年化营收快速放量，并被曝挖角谷歌 TPU 元老推进自研硅**：相关报道援引数据称，Anthropic 年化营收运行率已由 2025 年底约 90 亿美元升至 2026 年 7 月底超 650 亿美元，二季度初步营收超 115 亿美元并首次实现经调整营业利润转正；同时公司被指从谷歌招揽 TPU 资深架构师，推进“GPU + 自研芯片”的异构算力路线。::cite[4263]

## 模型、平台与开发者生态

- **Generalist AI 发布机器人基础模型 GEN-1.5：数秒示范即可掌握新动作、无需微调**：36 氪 8 月 22 日报道，硅谷机器人公司 Generalist AI 于北京时间凌晨发布新一代基础模型 GEN-1.5，可仅凭一段 3–12 秒的短视频“物理提示”示范完成拉拉链、拧盖子等操作类任务，无需更新权重或微调；报道称其投资方包括李飞飞（个人）、小米林斌、Zoom 袁征及英伟达。::cite[4274]

- **第三方报道 / 待官方确认：微软 365 Copilot 被指接入 Anthropic Claude 模型，降低对 OpenAI 单一依赖**：报道称微软正将 Claude Sonnet 4 与 Claude Opus 4.1 集成进 Microsoft 365 Copilot，用户可在“Researcher”工具与 Copilot Studio 中切换 OpenAI 与 Anthropic 模型，但 Copilot 仍以 OpenAI 为默认。::cite[4283]

- **第三方报道 / 待官方确认：Ornith AI 发布 Ornith-1.5 模型家族（MIT 许可、自我改进训练）**：报道称 Ornith-1.5 以 MIT 许可开放，提供 BF16/FP8/GGUF/MLX/NVFP4 等多种权重格式，原生上下文 262,144 token、经 YaRN 扩展可至约 100 万，并采用自我改进训练方法。::cite[4273]

- **第三方报道 / 待官方确认：SupraLabs 发布 25M 参数轻量模型 Supra2-Medium-Base**：报道称该模型基于 Qwen3 架构、从零预训练约 20B token 英文网页文本，面向数据高效缩放研究与内存受限的边缘部署场景。::cite[4272]
