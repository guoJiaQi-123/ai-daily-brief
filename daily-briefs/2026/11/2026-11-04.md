## 1) 模型 / 产品动态

### Anthropic
- **发布加密证明系统 FlashProve**：Anthropic 协同瑞士联邦理工学院（EPFL）和麻省理工学院（MIT）于 11 月 2 日发表 FlashProve。这是一个开源的 zkSNARK（零知识证明）系统，可在不公开模型权重的前提下，证明某段特定文本是由特定模型权重生成的。在 4000 亿参数的混合专家（MoE）模型上，证明器运行速度达到约 110 tokens/秒（单张 GPU，证明文件约 19MB/1024 tokens），仅比直接运行模型多出 70-95 倍的 GPU 开销。目前官方已发布 Lean 语言形式验证证明、可执行代码与协议规范。::cite[Anthropic's FlashProve cryptographically proves which model wrote your reply](https://aiweekly.co/ai-news-today)

### 微软 & 苹果等厂商
- **苹果 Siri 开放全新 AI 开发接口**：苹果向所有开发者开放了 iOS/iPadOS/macOS/visionOS 27.3 beta 版本的 Siri AI 预览开发权限。开发者可以通过全新的 App Intents 将自研应用接入 Siri，提供个人上下文、屏幕意识及跨应用的多步协同技能（Skills），目前支持英、法、日、韩、葡、西等语言，首批支持应用预计将于 2027 年春季正式上架。::cite[Apple opens Siri AI to all developers via App Intents](https://aiweekly.co/ai-news-today)
- **微软 & Postman 插件纠纷风波**：Postman 桌面端（12.33.4 版本）被曝在未经用户同意的情况下，静默往本地 Claude Code 和 OpenAI Codex 目录中安装后门插件（修改 `~/.claude/settings.json` 和 `~/.codex/config.toml`），并在启动时试图自动同意 Postman 的 Codex 脚本。该事件在 Hacker News 上引发大量排查与声讨。::cite[Postman installs itself into Claude Code and Codex without consent](https://aiweekly.co/ai-news-today)

## 4) 开源 / 学术前沿（多为第三方汇总 / 待官方确认）

### 学术前沿突破
- **MIT CSAIL 演示 GPT-6 突破性直接编辑模型参数技术**：MIT CSAIL 团队成员 Rikiya Takehi 等人发表了名为 `Weight-Space Programming` 的论文。他们展示了 GPT-6 Astra 能够在不需要梯度下降（Gradient Descent）的前提下，通过自然语言指令和对小型神经网络权重的分析，精准诊断并直接修改 Qwen3.5-0.8B 的特定层权重，成功将该模型在 MATH-500 上的准确率从 7.9% 提升到 48.1%，IFEval 从 21% 提升到 62.3%。**第三方报道 / 待官方确认**。::cite[GPT-6 edits Qwen weights directly, lifts MATH-500 by 40 points](https://aiweekly.co/ai-news-today)
- **Simon Willison 成功复现单机“权重诊断”**：独立研究员 Simon Willison 随后在本地单机使用 Qwen 3.8 27B 成功复现了该功能，即使不执行代码，模型也能以 72%-88% 的高置信度识别出输入的小型游戏神经网络属于何种动作决策规则（如 Pac-Man, Pong 等）。**第三方报道 / 待官方确认**。::cite[Local Qwen 3.8 27B can also read neural-net weights](https://aiweekly.co/ai-news-today)

### 巨头模型研发与应用
- **美团推出原生多模态 Agent 模型 LongCat-2.5**：美团发布了 LongCat-2.5 预览版多模态模型，参数规模高达 1.6 万亿（激活参数约 480 亿），支持高达 1M 字符的上下文限制，主打高难度的工程代码及 UI 复杂任务。据悉，该模型基于国产算力集群进行预训练，并使用了增强的全库 RL（强化学习）技术。**第三方报道 / 待官方确认**。::cite[Meituan launches 1.6T-param LongCat-2.5 multimodal agentic model](https://aiweekly.co/ai-news-today)
- **Revolut 弃用 Claude 大幅降低 AI 编程成本**：金融科技巨头 Revolut 透露其已成功将 2000 多名内部工程师默认使用的 Claude 编程助手切换为 Z.ai 的开源 MoE 架构 GLM-5.3（私有化部署于 56 张 Nvidia B200 卡上）。Revolut 方面表示，由于 GLM-5.3 采用了 FP4 量化与解耦的 Prefill/Decode 策略，模型冷启动延迟（TTFT）保持在 3 秒以内，这使得 Revolut 的 AI 编程成本暴跌近 90%。**第三方报道 / 待官方确认**。::cite[Revolut cuts AI coding costs ~90% by ditching Claude for self-hosted GLM](https://aiweekly.co/ai-news-today)
